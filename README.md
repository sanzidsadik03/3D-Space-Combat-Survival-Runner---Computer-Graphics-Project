# 3D Space Combat Survival Runner 🚀

A 3D space combat survival game developed using **Python, PyOpenGL, GLUT, and GLU**. The game features a fixed-forward flight system where the player controls a spaceship, avoids obstacles, collects power-ups, and fights enemy spacecraft across multiple waves.

### Features

* 🚀 3D player and enemy spaceship models
* 🔫 Forward-firing plasma cannons
* 👾 Multiple enemy waves with boss encounters
* 💥 Projectile, collision, and particle effects
* 🪙 Collectible coins and health hearts
* 🛡️ Power-ups including triple cannons and energy shield
* 🤖 AI Co-Pilot with auto-aim and auto-dodge
* 🧲 Coin magnet mode
* 🎥 Three camera modes: Third-Person, First-Person, and Orbit
* ⚡ Multiple speed levels that increase with waves
* 🌌 Animated 3D space corridor and starfield
* ❤️ Lives, scoring, waves, and victory/game-over states
* 🎮 Keyboard, mouse, and arrow-key controls

### Technologies

* Python
* PyOpenGL
* OpenGL
* GLUT
* GLU
* Math & Random modules

### Controls

* **W / S** — Move up/down
* **A / D** — Move left/right
* **Space / Left Click** — Fire
* **C / G** — Toggle AI Co-Pilot
* **M** — Toggle Coin Magnet
* **V / Right Click** — Change camera
* **P / ESC** — Pause/Resume
* **R** — Reset
* **Arrow Keys** — Movement / Orbit camera control

This project was developed as part of a **Computer Graphics course project**, demonstrating 3D modeling, transformations, animation, camera systems, collision mechanics, particle effects, and interactive gameplay using OpenGL.
